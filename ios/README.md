# iOS sender

This folder contains the native `PhoneTwinSender` app and the `PhoneTwinBroadcast` ReplayKit Upload Extension.

Open `PhoneTwinSender.xcodeproj` in Xcode. Both targets must use the same signing team and App Group. The native development endpoint is:

```text
ws://<MAC_IP>:8788/native
```

The complete signing, installation, permission, and broadcast tutorial is in the project root [README](../README.md#打包并安装-ios-app).
